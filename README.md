# 3. Why Excel WBS Master?

There are many tools available for creating WBSs (Work Breakdown Structures) and Gantt charts, ranging from free software to commercial products. These tools come in various forms, including dedicated applications and Excel-based templates. Many companies also create and use their own standardized templates, such as Excel files, as an internal standard.
In addition, many projects make use of project management software such as Redmine. When used in practice, these tools are designed to facilitate communication among team members through tickets, maintain records of discussions, and help track project progress.

However, after actually using them, each solution tends to have its own challenges, and to be honest, none of them feels completely satisfactory.
For example:
- Entering hundreds of work items through a dedicated user interface can be very burdensome.
- It is difficult to add new items or further break down tasks after the initial registration of work items.
- It is hard to obtain an overall view of long-term schedules and project status.
- It is difficult to understand the day-to-day situation and the status of individual team members.
- the tools are primarily designed for planning schedules and often do not adequately support the monitoring of daily progress.
- Some tasks require requests to be made to system administrators, meaning administrators must be assigned and maintained within the organization.
- Cells representing individual days in a Gantt chart often need to be manually color-coded, and graphical elements must be manually adjusted.
Many of these issues may sound familiar.

As a result, it is not uncommon for the WBS to become something that only the PM (Project Manager) or PL (Project Leader) spends time updating on a daily basis, without effectively serving as a tool for sharing project status with team members. In some cases, the WBS remains mostly unchanged from the initial project planning phase, while progress management is handled separately through other means.
To address these issues, I wanted to create a roadmap that would allow all team members to easily understand both the planned schedule and the latest project status, while also enabling updates to be made with minimal effort. Since there was also a need to operate a WBS and Gantt chart without introducing dedicated software, I decided to create one using Excel.

# 4. Features
   
At-a-glance Status:
Plans and actual progress are clearly visible. By entering progress as it happens, the latest status is displayed in an easy-to-understand format. 

Automatic Gantt Chart:
Simply enter dates to display planned and actual schedules as a Gantt chart on the same row. 

Task Dependencies:
Task relationships can be visualized using arrows within the Gantt chart. 

Auto-Drawing Borders:
Borders in the task information area are automatically drawn based on data in the preceding and succeeding rows. 

Flexible Comments:
Since the Gantt chart is drawn using cell formatting, you can freely enter comments or other data into the cells within the chart. 

Long-term Perspectives:
Multiple Gantt chart display functions are available to help grasp project status from a long-term perspective, such as monthly views. 

EVM Charts:
Capability to generate EVM (Earned Value Management) charts and graphs. 

Standard Excel Operations:
No special interface is required; task information can be entered using standard Excel operations. 

Multi-language Support:
The display language supports 10 languages, including Japanese and English. The calendar and day/month displays in the Gantt chart support even more languages. 

Instant Language Switching:
When the language is changed, the screen display updates instantly while preserving all input data.
